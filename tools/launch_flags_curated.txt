# Launch options (runtime/launch_flags.h): what the start screen knows about SAVAGEWIND_* environment flags.
# tools/gen_launch_flags.py scans runtime/ for every flag the code reads and writes runtime/launch_flags_table.c from
# the scan and this file. Run it after adding, renaming or removing a flag: `python3 tools/gen_launch_flags.py`
# (`make test-launch-flags` fails when the table is stale).
#
# A flag that is not listed here is still offered while typing (as "other", or "developer" when its name says it
# dumps, traces, logs, profiles or tests something). Only the lines below change how it is treated.
#
# Line format: group NAME | example value | description    (description: one short line, plain words, no dashes)
#
# Groups that can NOT be added from the start screen (a typed entry is refused with the reason):
#   internal  used by Savage Wind itself, or read before the saved options can be found
#   launcher  skips or locks the start screen, or hides the window: the player could not undo the entry
#   build     configures the game code build, not the game
# Group that is suggested first, as a flag a tester may be asked to set:
#   play      safe to try; the example value is what the suggestion fills in

internal SAVAGEWIND_REEXEC | | Counter for the automatic restart that finds free memory for the game.
internal SAVAGEWIND_LAUNCH_FLAGS_APPLIED | | Remembers which launch options this run started with.
internal SAVAGEWIND_DATA_ROOT | | Where Savage Wind keeps its files. It is read before launch options can be found.
internal SAVAGEWIND_LAUNCHER_AUTOUPDATE | | Tests: the start screen starts an offered update at once.
internal SAVAGEWIND_SETTINGS | | Another settings file. It is read before launch options can be found.
internal SAVAGEWIND_X | | An example name in a code comment.

play SAVAGEWIND_VK_NO_FEEDBACK_LOOP | 1 | Draws with copies instead of feedback loops. Fixes a wrong picture on some graphics cards, slower on others.
play SAVAGEWIND_VK_FEEDBACK_LOOP | 1 | Turns feedback loops on where they are held back for your graphics card.
play SAVAGEWIND_VK_GPL | 1 | Turns pipeline libraries on where they are held back for your graphics driver.

play SAVAGEWIND_VK_HEAP_IMPORT | 1 | Gives the game's memory to the graphics card by import instead of export.
play SAVAGEWIND_VK_SPARSE_HEAP | 0 | Sparse memory for the game. 1 forces it on, 0 forces it off.
play SAVAGEWIND_VK_NO_GMEM | 1 | Turns off the single memory mapping of the game's heap.
play SAVAGEWIND_VK_NO_PIPELINE_CACHE | 1 | Ignores the saved pipeline cache.
