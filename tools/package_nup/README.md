# NUP reference reader

`format.py` and `read.py` come from the MIT-licensed a55uka/nup reference
implementation at commit `a4840f06c94ddeb414eea5b33c9704ffe995f11c`, with small
changes for bounds validation and Python 3.10 compatibility.
`tools/package_import.py` selects content, validates output names and verifies the
contents of each extracted file.
