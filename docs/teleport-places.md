# Teleport places

Every place the teleport knows, with the number and name you can give it. How to turn the teleport on and open the
console: [Cheats and assists](cheats-and-assists.md#teleport-and-console-cheats).

Type the kind, then a number or a word of the name: `tp shrine 12`, `tp shrine oman au`, `tp tower central`,
`tp stable wetland`, `tp kakariko`. A name that matches several places lists them. `tp nearest shrine` (or `tower`,
`stable`, `village`, `landmark`, `korok`) goes to the closest one to where Link is. `goto` is the same command as `tp`.
In the game, `places <kind> [words]` shows the same lists, 40 at a time.

## Koroks

The game gives Koroks no numbers, so each one goes by the id the object map uses (like `H23`): `tp korok H23`.
`tp korok 10` counts all 900 in map order instead, square `A-1` first. The squares are the map's grid: letters from
west to east, numbers from north to south. `tp nearest korok` is often the easiest.
